# 📌 문제: MSA 분산 추적(Tracing) 병목 서비스 탐지

당신은 사내 트래픽 모니터링 시스템을 개발하고 있습니다. 하나의 사용자 요청(Trace)이 발생하면 여러 서비스들을 거치며 로그가 남는데, 각 로그의 단위를 스팬(Span)이라고 부릅니다.
어떤 스팬이 다른 서비스(자식 스팬)를 호출하면, 부모 스팬의 전체 시간(Total Time)에는 자식 스팬이 실행되는 데 걸린 대기 시간이 포함되어 있습니다. 따라서 특정 서비스에서 실제 연산에 소모한 '순수 실행 시간(Exclusive Time)'을 구하려면, 부모의 전체 시간에서 모든 직속 자식들의 전체 시간을 빼주어야 합니다.
단일 트레이스의 스팬 정보가 담긴 배열 spans가 주어질 때, 서비스별로 순수 실행 시간을 합산하여 시간이 가장 오래 걸린 순서대로 정렬해 반환하는 함수를 완성하세요. (단, 시간이 같다면 서비스 이름 기준 사전 오름차순으로 정렬합니다.)

## 🔍 실행 시간 계산 규칙
- spans의 각 요소는 "스팬ID 부모스팬ID 서비스명 시작시간 종료시간" 형태의 문자열입니다.
- 부모 스팬 ID가 "0"인 경우는 이 요청의 최초 진입점(Root Span)을 의미합니다.
- 스팬의 총 실행 시간(Total Time) = 종료시간 - 시작시간
- 스팬의 순수 실행 시간(Exclusive Time) = 총 실행 시간 - (모든 직속 자식 스팬들의 총 실행 시간 합)
- 자식 스팬들의 시간은 부모 스팬의 시간 구간 내에 완전히 포함되며, 자식 스팬들끼리 시간이 겹치지 않는 동기(Synchronous) 호출이라고 가정합니다.
- 동일한 서비스가 여러 번 호출되었다면(스팬이 여러 개라면), 해당 서비스의 순수 실행 시간을 모두 더해야 합니다.

## 제한사항
- spans의 길이는 1 이상 100,000 이하입니다.
- 시간은 1 이상 10,000,000 이하의 자연수입니다.
- 서비스명과 스팬 ID는 알파벳 대소문자와 숫자로 이루어져 있습니다.
- 반환 형식은 "서비스명 순수실행시간" 형태의 문자열 배열입니다.

## 입출력 예시

| spans | result |
|---|---|
| `["s1 0 API_GW 10 100", "s2 s1 AUTH 20 40", "s3 s1 DB 50 90"]` | `["DB 40", "API_GW 30", "AUTH 20"]` |
| `["1 0 WEB 0 50", "2 1 DB 10 20", "3 1 DB 30 40"]` | `["WEB 30", "DB 20"]` |

#### 예시 1번 설명:
- s1 (API_GW): 총 시간 90 (100 - 10). 자식으로 s2, s3를 가집니다.
- s2 (AUTH): 총 시간 20 (40 - 20). 자식이 없으므로 순수 실행 시간은 20.
- s3 (DB): 총 시간 40 (90 - 50). 자식이 없으므로 순수 실행 시간은 40.
- s1의 순수 실행 시간 = 90 - (20 + 40) = 30.
- 결과 정렬 (내림차순): DB(40) $\rightarrow$ API_GW(30) $\rightarrow$ AUTH(20)
