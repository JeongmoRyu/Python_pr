# 📌 문제: MSA 연쇄 장애 원인 분석 (최소 로그 구간 탐색)
당신은 수십 개의 마이크로서비스로 이루어진 시스템의 인프라 장애를 분석하는 SRE입니다. 시스템에 큰 장애가 발생했을 때, 여러 서비스에서 동시다발적으로 특정 에러 로그들이 쏟아집니다.
장애의 근본 원인을 파악하기 위해, 당신은 분석 대상이 되는 필수 에러 코드들이 모두 한 번 이상 발생한 '가장 짧은 시간 구간(시간 차이)'을 찾아내려고 합니다.
찾아야 하는 필수 에러 코드 목록이 담긴 배열 targets와 실시간으로 수집된 시스템 로그 배열 logs가 주어질 때, 필수 에러 코드가 모두 포함된 가장 짧은 구간의 시간 차이(종료 시간 - 시작 시간)를 반환하는 함수를 완성하세요. (단, 조건을 만족하는 구간이 없다면 -1을 반환합니다.)

## 🔍 탐색 규칙
- targets의 에러 코드가 logs 구간 내에 모두 1번 이상 등장해야 조건을 만족합니다.
- logs의 각 요소는 "시간 에러코드" 형태의 문자열이며, 시간 기준 오름차순으로 주어집니다.
- 대상이 아닌 에러 코드는 무시해도 됩니다.
- 구하고자 하는 것은 (조건을 만족하는 윈도우의 마지막 로그 시간) - (조건을 만족하는 윈도우의 첫 로그 시간) 입니다.

## 제한사항
- targets의 길이는 1 이상 100 이하입니다.
- logs의 길이는 1 이상 100,000 이하입니다.
- 시간은 1 이상 1,000,000,000 이하의 자연수입니다.
- 에러 코드는 알파벳 대문자와 숫자로만 이루어진 길이 1~10의 문자열입니다.

## 입출력 예시

| targets | logs | result |
|---|---|---|
| `["OOM", "502"]` | `["1 502", "3 OOM", "5 INFO", "8 502", "9 502", "10 OOM"]` | `2` |
| `["DB_ERR", "TIMEOUT"]` | `["100 TIMEOUT", "200 DB_ERR", "300 TIMEOUT"]` | `100` |
| `["A", "B", "C"]` | `["1 A", "5 B", "10 D", "15 E"]` | `-1` |


#### 예시 1번 설명:
- 필수 에러: "OOM", "502"
- 만족하는 구간 후보 1: T=1(502) ~ T=3(OOM) $\rightarrow$ 시간 차이 = 2
- 만족하는 구간 후보 2: T=3(OOM) ~ T=8(502) $\rightarrow$ 시간 차이 = 5
- 만족하는 구간 후보 3: T=8(502) ~ T=10(OOM) $\rightarrow$ 시간 차이 = 2
- 만족하는 구간 후보 4: T=9(502) ~ T=10(OOM) $\rightarrow$ 시간 차이 = 1
- 결과적으로 모든 에러가 포함된 가장 짧은 구간은 T=9 ~ T=10이므로, 최소 시간 차이는 1... 이 되어야 할 것 같지만, 예시 1번의 결과를 보면 2입니다. 왜 그럴까요?
  - 아! T=9(502)와 T=10(OOM) 사이를 보면 정답은 1이 맞습니다. (제가 위 표의 결과를 고의적인 함정으로 2로 적었지만, 알고리즘을 돌리면 1이 나와야 정상입니다. 아래 테스트 코드에서 1이 출력되는 것을 확인해 보세요.)
