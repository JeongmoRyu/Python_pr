📌 문제: 멀티 클라우드 CDN 최적 라우팅 (경유지 제한)
당신은 멀티 클라우드 환경에서 트래픽을 분산하는 CDN(Content Delivery Network) 시스템을 설계하고 있습니다. 클라우드의 각 리전(Region)은 노드(Node)로, 리전 간의 네트워크 연결 상태는 간선(Edge)으로 표현됩니다.
보안 및 네트워크 지연(TTL: Time To Live) 정책 상, 출발지(start)에서 목적지(end)까지 데이터를 전송할 때 최대 K개의 중간 리전(경유지)까지만 거쳐갈 수 있습니다.

네트워크의 총 노드 수 N, 연결 상태와 지연 시간이 담긴 edges, 출발지 start, 목적지 end, 그리고 허용된 최대 경유지 수 K가 주어질 때, 목적지까지 도달하는 데 걸리는 최소 지연 시간을 반환하는 함수를 완성하세요. (단, K번 이내에 도달할 수 없다면 -1을 반환합니다.)

## 제한사항
- N은 1 이상 100 이하의 자연수입니다. (노드 번호는 0부터 N-1까지 주어집니다.)
- edges의 길이는 1 이상 10,000 이하입니다.edges의 각 원소는 [출발노드, 도착노드, 지연시간] 형태입니다. (지연 시간은 1 이상 10,000 이하)
- K는 0 이상 N 이하의 정수입니다.

## 입출력 예시

| N | edges | start | end | K | result |
|---|---|---|---|---|---|
| `4` | `[[0, 1, 100], [1, 2, 100], [2, 3, 100], [0, 2, 500]]` | `0` | `3` | `1` | `600` |
| `3` | `[[0, 1, 100], [1, 2, 100], [0, 2, 500]]` | `0` | `2` | `0` | `500` |


#### 예시 1번 설명:
- 0 -> 1 -> 2 -> 3 경로: 지연 시간은 300으로 가장 빠르지만, 중간 경유지가 2개(1번, 2번 노드)이므로 제한(K=1)을 초과하여 사용할 수 없습니다.
- 0 -> 2 -> 3 경로: 지연 시간은 500 + 100 = 600이며, 중간 경유지가 1개(2번 노드)이므로 제한(K=1)을 만족합니다.
- 정답은 600입니다.
